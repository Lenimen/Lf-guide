THE LF METHOD

Page de test de l'app élèves. Rien n'est enregistré, aucune donnée ne part nulle part sauf le code que tu copies toi-même.

1. Installation …

Ouvre cette page dans Safari, puis :

  1. touche le bouton Partager (le carré avec la flèche) ;
  2. choisis « Sur l'écran d'accueil », puis « Ajouter » ;
  3. ouvre l'app « LF Test » depuis ton écran d'accueil et continue là-bas.

L'app est ouverte depuis l'écran d'accueil, en plein écran. C'est bon.

2. Notifications …

Touche le bouton, puis « Autoriser ».

Dernière étape : copie ce code et colle-le dans le fil Claude. Je t'enverrai une vraie notification depuis l'extérieur.

3. Scan de code-barres …

Prends un produit de ta cuisine et scanne son code-barres.

4. Sans réseau à tester

Mets ton iPhone en mode avion, ferme l'app puis rouvre-la depuis l'écran d'accueil. Si cette page s'affiche, c'est bon : à la salle, une séance pourra s'enregistrer sans réseau.

Résultat à me renvoyer

Copie ce résumé et colle-le dans le fil Claude, avec le code des notifications.
